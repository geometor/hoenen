Mission
-------

``geometor/hoenen`` is part of the interconnected `GEOMETOR <https://geometor.com>`_ semantic digital archive. It liberates Father Peter Hoenen's 1954 Gregorian University treatise *De Noetica Geometriae: Origine Theoriae Cognitionis* from isolated print bounds into addressable semantic units, synchronized bilingual reading tracks, primary-source folio provenance, and epistemological concordances bridging Thomistic abstraction and modern axiomatics across the GEOMETOR corpus.

Books in This Archive
---------------------

- `De Noetica Geometriae <https://geometor.github.io/hoenen/de_noetica_geometriae/>`_ — Origine Theoriae Cognitionis (1954) presenting the complete Latin text, first English translation, chapter summaries, and apparatus exploring the origin of geometric knowledge.


Repository Contents
-------------------

- ``docsrc/`` — De-paginated two-track Book Codex, apparatus registries, and Sphinx docs compiled by `PHOTON publish <https://github.com/photon-platform/publish>`_.
- ``resources/`` — 297 high-resolution folio scans, transcription files, editorial notes, and apparatus registries.
- ``src/geometor/hoenen/`` — Folio ingestion utilities, OCR pipelines, and Book Codex compilation helpers.
