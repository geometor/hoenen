# Translation Benchmark & Comparative Analysis: Praefatio

**Author:** Antigravity (Google DeepMind)

**Date:** October 1, 2026  

---

## 1. Executive Summary

As part of the launch of the translation workspace on branch `feature/english-translation`, we performed an independent, scratch translation of Father Petrus Hoenen’s *Praefatio* (*De Noetica Geometriae*, 1954). We then benchmarked this fresh rendering against the prior translation generated by Model 3.1.

The benchmark demonstrates clear qualitative advancements across four key criteria:
1. **Defect Elimination**: Remediation of line-split artifacts and erroneous Markdown footnote tags inherited directly from optical scans.
2. **Scholastic Metaphysical Precision**: Deeper fidelity to Thomistic terminology (*in actu exercito* / *in actu signato*, *habitus*, *esse actuale*).
3. **English Stylistic Fluency**: Unrolling periodic, formal Scholastic Latin clauses into natural, authoritative academic English without syntactic stiffness or calques.
4. **Scholarly Apparatus Completeness**: Translation and expansion of bibliographic citations, including proper handling of Latin scholarly conventions (*resp.* = *respectively*, not *or*).

## 3. Key Methodological Lessons for the Workspace

1. **Preserving Scholastic Technical Vocabulary in Context**:
   - Rather than settling for bare literalisms ("exercised act"), we retain the Latin phrase parenthetically while providing the epistemological sense in the English phrasing.
2. **Cleaning Typographical/Mechanical Artifacts**:
   - Every text file must be scrubbed of trailing hyphenations and bracketed dates that confuse Markdown parsers.
3. **Apparatus Enrichment**:
   - Readers of the English translation benefit immensely when Latin titles in footnotes (such as articles in *Gregorianum*) are glossed with clear English translations.
